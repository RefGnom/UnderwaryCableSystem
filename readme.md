Заказ на 3D-печать (Кабель-менеджмент)
Материал: PETG.
Цвет: Черный.
Постобработка: Удаление поддержек (если будут), шлифовка не требуется.
Технические требования по группам файлов:

1. Плиты-основы (Grids):
	* Заполнение: 15-20% (сетка или соты).
	* Стенки: 3 слоя.
	* Важно: Печатать плашмя, без поддержек.

2. Держатели и Кронштейны (Mounts/Brackets) — детали под нагрузкой:
	* Заполнение: 40-50%.
	* Стенки: 4-5 слоев (это важнее заполнения для прочности отверстий и крючков).
	* Ориентация: Печатать на боку, чтобы слои шли вдоль нагрузки.

3. Мелкие клипсы и пины (Clips):
	* Заполнение: 100% (сплошные).
	* Важно: Это мелкие детали, они должны быть максимально прочными.
